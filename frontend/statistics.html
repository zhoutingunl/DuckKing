这些指标能说明什么？

识别返回率 = 返回非空文字的已结束轮次 / 已结束且提交录音的轮次。回复结束率 = 收到云端正常回复结束事件的轮次 / 已结束且走云端的提交轮次。本地命中率 = 完整匹配并选择本地执行的轮次 / 已完成路径判定的本地优先轮次；不代表识别或意图准确率。本地提示音不计作云端回复。进行中和录音未提交的轮次不进入这两个比率。

动作完成率只统计真正被控制器受理且已经结束的动作；重复 MCP 请求不重复计数。完成表示控制流程正常结束，不保证物理位移或转角达标。

识别准确率（CER / WER）、意图正确率、动作顺序符合率，需要与人工标注的原话和目标动作比较。这里展示识别文字与实际动作，供核对，不自动给出准确率。

延迟使用本地单调时钟。这里没有测量麦克风硬件、浏览器扬声器、画面呈现或 MuJoCo 物理反馈延迟；语音回复结束也不等于扬声器已经播完。结束录音之前返回的阶段只出现在时间线，不纳入非负延迟分布。
