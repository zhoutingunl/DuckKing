# 持续使用体验

入口 [`experience.html`](https://ztmonitor.qbox.net/duckking/experience.html)，首页、练习场、自动剧场、现场互动均有新标签页链接。旧 `statistics.html` 继续提供单个房间当前进程的最近 500 轮诊断；新页保存跨重启、发布、房间回收的技术统计。

## 页面读法

默认最近 7 天、日常使用、全部房间。可以切换 1 小时、24 小时、30 天、90 天，以及页面、场景、设备大类、模型缓存、动作后端、房间、发布提交。每项显示样本数、均值、P50/P90/P95；nearest-rank 分位数精确计算，不以桶中值近似。样本不足 20 个明确标记。趋势按小时或 UTC 日分桶，标签按浏览器时区显示；空白时段不补零。CSV 只导出当前筛选的聚合数据，不包含语音正文。

浏览器与服务器为两组观测，不将它们相加当作用户数，也不将两组均值相减估算网络耗时。本地命中、直连灵矽、本地后转交灵矽分别统计；转交轮次可同时有本地和云端识别阶段。

| 指标 | 起点 | 终点与边界 |
| --- | --- | --- |
| 模型可见 | 首页/练习场模型加载开始 | 模型组装、渲染之后的动画帧；不是屏幕出光 |
| 场景可见 | 练习场、剧场、工坊点击加载 | 物理场景准备、模型读取、组装及绘制后的动画帧 |
| 首页首次可见 | 浏览器导航开始 | 首个官方模型显示；场景页的用户停留时间不算进此项 |
| 浏览器本地/灵矽识别返回 | 松开按钮、提交结束录音之前 | 首条对应引擎非空识别文本到达页面 |
| 浏览器动作回执 | 同上 | 控制器真实受理的通知到达页面；工坊任务取首个非管理性停止动作，不把整段计划受理当作实际起步；不代表实际位移 |
| 浏览器首段音频 | 同上 | 首个回复音频帧到达；不代表已从扬声器出声 |
| 服务器识别/动作/音频 | DuckKing 收到结束录音 | 识别文字、实际动作受理或首帧音频到达服务端 |
| 本地 ASR 工作进程 | 服务端发起离线识别请求 | 工作进程排队、推理与返回 |

采集首页、动作练习场、自动剧场、现场互动工坊。原模型日志接口仍兼容；新采集另走 `/api/experience`，不会把同一加载的旧日志再导入一次。语音收集浏览器接收时机，包含手机网络与现有 HTTPS 长轮询调度。通过单调时钟测相对耗时，统计时间范围按服务器首次收到记录的时间筛选，不信任客户端墙钟。

## 持久化与边界

`DUCKKING_DATA_DIR/experience.sqlite3` 使用 SQLite WAL，文件权限 `0600`。YZH737 对应 `/var/lib/duckking/experience.sqlite3`，在版本目录外，常规升级不会删除。所有房间共享一个统计库，保留房间维度；新房间实例的轮次编号不会覆盖旧实例。无需新增依赖或改动 ai_gateway。

每条加载/语音使用随机临时测量 ID，不是设备或用户身份。浏览器与服务器分开写入，按 ID、观测端和递增序号幂等更新，重试不加样本，迟到旧更新不覆盖终态。服务器使用私有语音日志的结构化阶段，持久化时只选取时延与枚举字段，不保存文本、录音、IP、原始 User-Agent、密钥或设备身份。公开查询仅返回聚合数据。

写入通过 2,048 项有界后台队列，避免磁盘写入阻塞语音/物理事件循环；溢出与写盘失败显示丢弃计数，不让语音任务失败。最多保留 90 天、50,000 条观测，按首次接收时间淘汰；有写入时执行清理，查询窗口也不超过 90 天。可用 SQLite backup API 在线备份，不能只复制正在写入的主文件而忽略 WAL。

上报每批最多 20 条、32 KiB；只接受列举的字段、枚举及 0–86,400,000 ms 有限数值。同源约束与其他 API 一致。页面后台刷新周期 30 秒，隐藏时不查询；技术采集仍记录是否曾进入后台。延迟表成功加载与失败加载分开，语音未观测阶段不补零；已经到达的阶段即使后续失败仍纳入对应延迟。未结束且超过 3 分钟无更新的记录显示“失联”，不会当作成功。

浏览器批次使用 keepalive、小批次有限重试，仍然可能在断网、页面崩溃、直接杀进程时丢失。采集状态和丢弃量必须一起看，不能声称覆盖全部访问。来源标签为客户端申报，不是身份认证，公开演示站点的数据不适合做可信计费。

## 基准与验收样本

- `interactive`：普通浏览器现场使用，默认展示。
- `demo`：自动剧场的预录语音实连轮次，不能视为真人口令分布。
- `verification`：`navigator.webdriver` 自动化浏览器或地址带 `measurement=verification`；公网验收不污染日常使用。
- `unattributed`：没有上报上下文的旧协议客户端、服务器脚本。此类服务器记录不会自动归入日常使用。

既有同一句合成口令、每条路径 10 轮的结果仍在 [演示视频说明](DEMO_VIDEO.md)，是固定输入的对照基准。不能补成历史真实用户数据，也不自动导入此页。识别准确率、意图正确率仍需要人工标注，此页不从“返回了文字”推断准确率。

## 验证

`tests/test_experience.py` 覆盖重启读取、分位数、维度筛选、幂等与乱序、缺失/失败/失联、容量和保留期、磁盘/队列失败、字段/来源/体积验证和服务器转交链路。浏览器验证包括真实模型加载上报、筛选/趋势/导出/移动宽度，以及明确标记为协议替身的本地→云端回退计时；前端单元覆盖打断、排队录音与恢复不冒充成功。
