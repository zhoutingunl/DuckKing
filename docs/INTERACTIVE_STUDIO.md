# 现场互动工坊

入口 `studio.html`，从“演示场景 → 现场互动”进入。原 `demos.html` 十二幕以及“预录对白 / 灵矽实连预录指令”两种方式保留。工坊使用真人麦克风；每幕另提供明确标为“本地排练”的按钮。现场模式固定走灵矽，不将本地脚本误标为云端理解。

## 按施工顺序接入的十项

| 场景 | 本轮增量 | 操作示例 |
| --- | --- | --- |
| 临场小导演 | 1–6 步受限动作、头部/原地约束、新计划替换旧计划 | “演一只不想上班的鸭；只用头，最后摇头。” |
| 嘴硬快递员 2.0 | 夹持保留、剩余仿真行走时间、从实际阶段继续 | “开始送货”“停，别松嘴”“继续送” |
| 评委当指挥 | 四鸭可点名、替换待唱队列、站稳后开始本地声部 | “C 先唱，再 A”“下一位换 B” |
| 鸭子的声音身份 | 三种样本试听、私有音色配置、下一轮 TTS 参数 | 连接后选择音色，再说一句新话 |
| 我教你一个暗号 | 草稿、下一轮确认、私有持久化、版本、修改和删除 | “‘下班’就是摇头坐下”“确认”“删掉摇头” |
| 世界杯小教练 | 只读观察、明确摆球、踢已准备的球 | “先看看，别动”“摆到右脚前”“踢球” |
| 鸭王说 | 对本轮识别原话检查前缀、更新规则、禁止绕过、停止例外 | “只有鸭王说才动”“点头”“鸭王说点头” |
| 会追问的橡皮鸭 | 记录已确认事实、修正时撤回旧事实、一次追问、身体反馈 | “接口报错”“其实请求根本没发出去” |
| 专注搭子 | 坐稳后计时、延期、取消、站稳后提醒 | “十秒后叫我”“再延十秒” |
| 换班不换鸭 | 两个专用智能体、白名单选择、重连并结束旧会话 | 严教练 / 摸鱼搭子对同一个问题作答 |

这些是软件交互原型，不代表新增实体硬件验收。高级动作仍由真实 MuJoCo 后端承担；不会在失败后退到动画预览。

## 任务与结果

`Studio` 归属于每个房间的物理控制器。任务有版本、状态、步骤与实际动作结果。替换或停止会取消整段未来动作；每步失败后终止。动作配方使用允许列表和 Pydantic 校验，不运行模型生成代码。单次配方最多六步、二十秒。头部注视是固定方向的限幅轨迹，不是人脸跟踪、声源定位或新增视觉能力。

搬运继续仅支持已稳定夹持、在行走阶段中断的固定轻棒任务。记录尚未消耗的仿真行走时间，继续时不重新抓取、不重新走完整距离。夹取、开嘴放下等其他中间阶段不保证恢复，失败会要求检查或重置。夹持期间不增加说话开嘴动画。

四鸭复用八秒《欢乐颂》主旋律短句，为临场修改队列留出时间。慢速软件渲染会逐级降低画布分辨率，保留原模型及真实物理状态。队列修改只替换尚未开始的独唱；当前歌手唱完坐回再交接。按住说话打断云端确认时保留演唱，以便修改待唱队列；“停止全部任务”或断开语音仍立即停止。起身和坐回由真实姿态与接触验证。前端根据已确认的独唱者播放本地合成声部，物理状态停止更新或失稳时停音。这不是云端生成音乐或 BLE 同步。

踢球练习场原有“一键定点踢球”保持兼容；工坊教练使用独立的观察、准备、踢球步骤。观察没有位姿写入；踢球不会自动摆球，换脚或球离开准备区会明确拒绝。成功由所选脚接触与实际位移共同确认。

计时以服务器单调时钟计数，从确认坐稳之后开始。延期修改同一任务的截止时间；停止、换幕、断开语音或关闭房间会取消任务；打断回复以说出新的延期命令时保留已开始的安静计时。到期先真实站稳，再请求当前空闲灵矽会话播报；若当前仍在回答，最多等待二十秒并可随时取消。没有可用云端会话或等待超时时只提供明确标为本地的任务结果，不伪造云端声音。

## 声音与角色

`frontend/public/voice-samples/` 是 macOS Eddy 中文合成语音经离线滤波后的三种样本，约 22 秒，分别为轻鼻音、轻沙哑加鼻音、较重鼻音。它们是试听/训练素材，不是克隆后的声音。处理、文本和 SHA256 在 `manifest.json`，可通过 `scripts/build_duck_voice_samples.py` 重建。

音色克隆状态必须达到官方 `Success` 才写入可用音色配置。当前账号检查结果是 free/lite/pro 三档克隆额度均为零，未发起训练、未生成克隆成功记录。待额度具备后使用推荐样本训练，再以未出现在训练样本中的句子验证。

私有 `voice-profiles.json` 位于 `DUCKKING_DATA_DIR`，保存音色 ID 和专用智能体 ID；子房间读取同一份白名单，但会话、动作和任务彼此独立。API 只返回配置键与显示名称。用 `scripts/setup_studio_voices.py --agents` 创建/更新互动工坊专用智能体及两个 DuckKing 专用角色；脚本不修改其他名称的智能体。`--sample-url <公开音频URL>` 检查免费额度并创建/等待一次克隆，不自动重复训练或消耗付费额度。

音色通过 `listen.agent_params.voice` 在下一轮输入生效，保持原智能体；切换角色通过握手 `X-Agent-ID`，需要结束旧会话并重连。当前角色切换为页面控件操作，不能声称实现了跨智能体会话记忆迁移。

官方依据：[音色与智能体切换](https://linx.qiniu.com/docs/xrobot/platform/agent-voice-switch)、[音色克隆](https://linx.qiniu.com/docs/xrobot/api/voice-clone)、[智能体 API](https://linx.qiniu.com/docs/xrobot/api/agent)。

## 验证记录

开发分支已验证：旧计划替换、外部停止、非法计划不执行、错误步骤阻断；三个不同位置的真实夹持暂停/继续；真实四鸭 C→A 改为 C→B；配方下一轮确认/版本重载；游戏漏口令和绕过拒绝；事实修正；提醒延期与取消；踢球观察无位置写入、错误脚拒绝、正确脚真实触球；协议音色字段和智能体握手；公开 API 不返回私有 ID。

浏览器已检查桌面导演替换、移动尺寸十项入口、试听来源标识，以及确认 C 已站稳开唱后将后续 A 改为 B，声音调度和物理完成顺序均为 C→B。

真实灵矽与 MuJoCo 联调已覆盖导演、暗号草稿/确认/执行、踢球观察/准备/实际触球、游戏配置和有无口令、事实纠正、提醒安排/延期/取消、独唱排队。输入为系统合成的全新语音，不是真人麦克风准确率测试，也不是实体扬声器验收。首轮曾出现游戏只口头答应和追问未记事实，随后增加专用提示词、按节目缩小工具列表并阻止绕过；复测确认规则和事实写入、实际动作完成。云端仍可能说得较长，一轮只有一个问号也不保证只有一个语义问题，展示应查看任务结果而非只听口头确认。

两个角色以同一段合成输入完成真实云端对照，分别返回不同回答和音频；该项使用预览后端且未请求动作，不是物理能力测试。推荐鸭嗓仍处于样本试听阶段。
