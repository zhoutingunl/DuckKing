# 原创贡献与复用边界

## 开发前基线

`v0` 对应提交 `1c0f123`，为空树，早于本项目全部应用代码。目标仓库起初为空，必须先有基础分支才能创建 GitHub PR，因此唯一直接初始化提交不含任何文件。之后的文档与代码都通过 PR 合入。

GitHub 已对 `v0` 设置禁止更新、禁止删除的规则；对 `main` 设置必须 PR、必须通过 `quality` 检查、禁止强推和删除，且对管理员生效。

## 贡献归属

| 内容 | 来源 | 本项目贡献 |
|---|---|---|
| 工作台、交互记录与动画脚本 | 本项目原创；当前鸭子外观复用官方网格 | 界面、状态联动、明确的预览/真实连接边界 |
| 实验性嘴部搬运 | 官方外观的机构改编与本项目控制 / 接触验收 | 近似铰链、接触垫、固定轻载搬运；未标定真机 |
| 动作控制层 | 本项目原创 | 限时、取消、去重、状态、错误反馈 |
| 灵矽客户端 | 根据公开协议自行实现 | OTA、设备身份、Opus、半双工、端侧 MCP 与浏览器音频 |
| 官方 robotd 适配器 | 根据公开接口自行实现 | 遥测订阅、连续意图、头部姿态保留与仿真实测 |
| 自动化测试与协作流程 | 本项目新增 | 覆盖率门槛、协议测试、浏览器测试、PR 与协作规范 |
| 本地优先语音 | sherpa-onnx / SenseVoiceSmall 推理，本项目路由 | 有界录音、整句匹配、一次性云端回退、房间隔离与统计；没有训练识别模型 |
| 十二幕演示与音乐 | 本项目剧本，官方／公共领域谱面与用户音源 | 可取消编排、实际物理结果验收、浏览器合成；不声明 BLE 同步或云端作曲 |
| 部署与可追溯记录 | 本项目发布与元数据实现 | 独立 Linux 服务、提交差异、绑定准确提交的后端覆盖率 |
| robotd / MuJoCo body / 策略与官方模型 | Pollen Robotics 等上游 | 外部依赖，不纳入本项目原创代码声明 |
| Three.js、FastAPI、libopus 等 | 对应开源项目 | 使用依赖，不声明为自行开发 |

依赖版本由 lock 文件管理。官方仿真源码留在外部目录，不将大体积模型或上游代码复制进应用仓库。官方模型画面及录制的视频保留来源与许可说明，参见 [媒体说明](media/README.md)。
