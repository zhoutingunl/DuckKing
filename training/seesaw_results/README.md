# 自由配重停靠 CPU PPO

当前契约 `seesaw-v4-passive-docking`：鸭子走位使被动板面倾斜，重力推动无电机配重，目标是送回红色区并减速停稳。详见 [设计说明](../../docs/SEESAW_COACH.md)。

## 本次实测

单采样进程、单 Torch 线程 CPU，新增采样 **131,072 步**。第 **98,304 步、1,596.98 秒（约 26 分 37 秒）**达到连续两次验证 ≥18/20 的门槛，实际两次均为20/20。最终选中本阶段131,072步策略；完整采样、验证与400个独立对照回合耗时 **2,205.16 秒（约 36 分 45 秒）**。

| 控制器 | 成功 / 100 | Wilson 95% 区间 | 末尾距停靠中心均值 | 平均绝对板角 |
|---|---:|---:|---:|---:|
| 任务 PPO | 98 | 93.0%–99.4% | 1.58 cm | 1.364° |
| 只回中心站定 | 0 | 0.0%–3.7% | 35.00 cm | 5.750° |
| 官方站定 | 0 | 0.0%–3.7% | 35.00 cm | 5.468° |
| 仅配平板面规则 | 0 | 0.0%–3.7% | 29.74 cm | 2.387° |

末尾距离使用绝对值；板角先在每回合任务 tick 中平均，再对回合平均。PPO两次失败（30018、30056）均未在18秒末完成停靠，距目标分别约30.6 cm、21.0 cm，报告完整保留。100个环境种子来自一次训练，不是100次独立训练；该比例不是泛化保证。

默认展示种子0用服务端JSON推理回放：配重初始20.1 cm，先滑到导轨端部，鸭子压板引导其回返并制动；最终距中心0.37 cm、速度0.80 cm/s、末尾连续停靠7.2秒。这个单例不参与选择checkpoint，不能替代独立测试。

## 实验身份

- 板面与滑块均无执行器、无回正弹簧、无预设轨迹；全模型只有鸭子的14个执行器。红色区没有吸附或锁定。
- 成功：18秒无跌倒，末尾连续1秒配重中心在±4 cm内、速度<2.5 cm/s、板角<2°、角速度<4°/s且有脚部支撑。
- 继承有驱动v3的180,224步actor，保留前17个观察列、删除周期列；critic及优化器重新初始化。导出步数311,296＝历史来源180,224＋本阶段131,072，不是全部开发试验成本。
- 训练随机种子42，环境训练种子从520001起；验证20000–20019，每8192步一次；最终测试30000–30099，四种控制器同种子对照。测试种子不参与checkpoint选择。
- 选策略按验证成功率优先、平均回报次优。`policy.json`是选定策略；`early.json`是迁移后、本阶段学习前的策略，不能称为随机0步网络。
- `report.json`保存真实训练、验证和逐回合测试记录；`environment.json`记录本机实际解释器依赖。服务不需要PyTorch。
- 墙钟时间包含同时开发/浏览器测试的资源竞争，不含历史任务训练、前置物理探查及之后页面验收；不是独占机器或Linux服务器基准。

## 复现

输出目录必须尚不存在，使用 `training/requirements.txt` 的独立CPU解释器：

```sh
PYTHONPATH=src .duckking/balance-venv/bin/python training/train_seesaw.py \
  --output .duckking/seesaw/passive-reproduce --steps 131072 --seed 42 \
  --warm-start training/seesaw_results/driven-v3/policy.json
```

省略warm-start为从随机任务策略开始的另一个实验。不同平台数值库可能改变训练轨迹。

## 对照边界与历史

回中和配平规则是简单对照，不是针对停靠任务调优的最强传统控制器；不能据此声称PPO优于所有传统方法。冻结官方步态、横移/朝向反馈和重力合力矩观察/奖励均为先验，尚未验证实体迁移或未知质量/摩擦泛化。

历史静态任务与有驱动任务分别见 [static-v2](static-v2/README.md)、[driven-v3](driven-v3/README.md)。旧版88/100和99/100不能用于当前任务。服务拒绝加载它们，网页也不把旧契约/不匹配模型哈希的报告显示为当前成绩。
