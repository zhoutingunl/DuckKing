These are synthetic regression recordings, not recordings from a user or an iPhone.
Generated locally with macOS `say -v Tingting`, converted to 16 kHz mono PCM16 with ffmpeg.

- local-command.wav: 向前走再向左转再向右转
- negated-command.wav: 不要前进

Used to test actual offline model loading, inference and whole-sentence routing.
Passing these fixtures does not establish accuracy in noise, with accents, or on phone microphones.
